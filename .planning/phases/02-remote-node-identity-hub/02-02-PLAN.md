<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| node → hub auth | Untrusted bearer must be proven to own the targeted node_id before any write. |
| platform credential vs node credential | MEMORY_API_KEY and the per-node bearer must authenticate only their own surfaces. |
| optional workflow module → server boot | The node bearer must never gate server startup. |

## STRIDE Threat Register (ASVS L1; block on high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-02 | Tampering / Elevation | events handler cross-node write | high | mitigate | store.nodeOwnsBearer(pathNodeId, hash) gates every write; mismatch → 401 before any insert (Task 1). Proven by intended-reason red control. |
| T-02-03 | Information Disclosure | bearer isolation comparison | medium | mitigate | timingSafeEqual over fixed-length sha256 digests for the MEMORY_API_KEY isolation check (Task 1). |
| T-02-05 | Denial of Service | events batch / payload size | medium | mitigate | Zod .min(1).max(500) + payload byte ceiling; 400 with no partial write (Task 1). |
| T-02-07 | Denial of Service | node-bearer boot coupling | high | mitigate | No node credential in findMissingRequiredEnv's checked set (startupValidation.ts:127-141); asserted by a startup-validation.test.ts injectable-EnvReader control PAIRED with a positive control, so the assertion is not vacuous (Task 2). |
| T-02-01 | Information Disclosure | rejection paths / logs | high | mitigate | Rejections never log the raw Authorization value; only status + node_id/client_seq counts are logged (Tasks 1/2). |

Fail-open (copying auth.ts's throw-on-missing-env onto the node bearer) is explicitly rejected: every
node-credential failure returns 401/400 and never falls through to a write.
</threat_model>
