<objective>
Discharge criterion 5 mechanically, and leave the repo's own test-command documentation honest about
what this phase added.

Purpose: `03-CONTEXT.md` D-10 is explicit that a count comparison (`357 passed / 9 failed`) hides a real
regression whenever one break coincides with one flaky recovery — and this phase adds new tests to the
same suite, so the total will not be 357 on the next run regardless. The only comparison that
discriminates is name-for-name over the same file set, which is why 03-01 captured identities and
outcomes rather than a tally. This plan runs the other half and requires an empty diff.

The second task is small and load-bearing for a different reason: CLAUDE.md documents its permission
grants as an inventory and says so in the file, warning that a stale one reads as a complete list. This
phase adds one file that spawns a server process and two that write under `/tmp`. Leaving them
unrecorded is how the inventory stopped being true the previous time.

Output: `03-REGRESSION-FINAL.txt`, an empty `diff` against the baseline, a measured corpus-integrity
check, and a current grant inventory.
</objective>
