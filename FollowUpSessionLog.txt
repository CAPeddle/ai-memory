### Key Discoveries (Docker Validation Session)
1. **AGE `v1.7.0` does not exist for PG15.** Correct latest stable tag: `PG15/v1.6.0-rc0`. AGE v1.7.0 is only for PG17/PG18.
2. **Fortinet SSL proxy intercepts HTTPS inside Docker.** `git clone https://github.com/...` fails with SSL cert error. Solution: download tarball on host, COPY into image. `docker/postgres-age/age-v1.6.0-rc0.tar.gz` added to repo.
3. **`flex` and `bison` required for AGE build.** `postgres:15` base image does not include them. Added to apt-get.
4. **AGE v1.6.0 does not support `|` in relationship type selectors.** `[:LIKES|INTERESTED_IN*1..3]` causes a parse error. This feature requires AGE v1.7.0 (PG17+ only). Workaround: explicit chained MATCH clauses. Workaround confirmed functional — fact inference returns `flowers`.
5. **MCP container health check shows "unhealthy"** because the `/health` endpoint is not implemented — but the server is running functionally on port 3000. Not a blocker.
