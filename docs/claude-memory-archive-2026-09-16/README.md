# Claude Code auto-memory archive for ai-memory (captured 2026-09-16)

Two Windows-side Claude Code memory stores that referred to this project, copied here when the
Windows laptop's shared memory index was curated (workspace-root launch plan, PRI-5802, unit U3).
They are the raw memory files as Claude Code wrote them: YAML frontmatter (`name`, `description`,
`metadata`) followed by the fact, its **Why**, and **How to apply**.

- `shared-store/` — the four ai-memory entries that lived in the laptop-wide index
  (`~/.claude/projects/C--projects/memory/`). These carried the note "project not found on disk
  as of 2026-08-31", which is why they were curated out.
- `c--projects-ai-memory-store/` — the whole per-project store that a lowercase-path launch
  (`c:\projects\ai-memory`) created on the Windows side, including its own `MEMORY.md` index.
  Several overlap the shared-store files (the shared copies were consolidated from these on
  2026-08-31); the rest are only here.

Nothing here is loaded automatically. Extract what still holds into this repo's own instructions
or a WSL-side memory store, then delete this directory.
